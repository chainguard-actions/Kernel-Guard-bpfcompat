# Kernel-Guard/bpfcompat

Validate eBPF .bpf.o artifacts across Linux kernel profiles and fail CI on compatibility regressions.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/Kernel-Guard/bpfcompat](https://github.com/Kernel-Guard/bpfcompat).
